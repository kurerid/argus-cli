# Argus

Argus — разрабатываемый CLI-инструмент для анализа изменений между
ветками Git и подготовки отчёта о релизе.

## Требования для сборки

- Go 1.27 или совместимая более новая версия.
- Доступ к зависимостям Go при первой сборке.

## Сборка

Из корня проекта:

```bash
mkdir -p bin
go build -o bin/argus .
```

Для сборки CLI не нужны Node.js, браузер или сервер базы данных.

## Запуск

```bash
./bin/argus --help
./bin/argus --version
```

При запуске без аргументов отображается справка. Неизвестная команда или
флаг завершаются с ненулевым кодом.

## Структура

- `main.go` — входная точка.
- `cmd` — CLI на Cobra.
- `internal/config` — будущая конфигурация.
- `internal/git` — будущая работа с Git.
- `internal/model` — будущие модели данных.
- `internal/analysis` — будущий анализ.
- `internal/render` — будущий рендеринг отчёта.

Пакеты внутри `internal` пока не реализованы. Они не должны зависеть от Cobra.

Путь модуля `argus-agent` используется локально и будет заменён на
фактический адрес репозитория при выборе места публикации.
